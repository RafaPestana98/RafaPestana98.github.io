# Portfólio — Rafaela Pestana

Portfólio pessoal de projetos em Dados, Power BI, Machine Learning e desenvolvimento.

## Estrutura

- `index.html` — página principal do portfólio
- `assets/screenshots/` — prints dos dashboards e apps (uma pasta por projeto)
- `assets/icons/` — ícones ou imagens auxiliares
- `certificados/` — PDFs dos certificados de formação
- `projetos/` — espaço reservado para páginas individuais de projeto (opcional, futuro)

## Como publicar (GitHub Pages)

1. Cria um repositório no GitHub (ex: `rafaela.github.io` ou `portfolio`)
2. Faz upload de todos estes ficheiros e pastas
3. Em Settings → Pages, ativa o GitHub Pages a partir do branch `main`
4. O site fica disponível no link gerado (ex: `https://teu-user.github.io/portfolio`)
